# PRD: Quiz Game

## 개요

- 터미널에서 실행되는 Python 퀴즈 게임
- 사용자는 메뉴에서 퀴즈를 풀거나 새로운 퀴즈를 추가한다.
- 저장된 퀴즈 목록과 최고 점수를 확인할 수 있다.
- 퀴즈 데이터와 최고 점수는 `state.json` 파일에 저장한다.

---

## 역할

### 플레이어

- 퀴즈를 풀고 점수를 확인한다.

### 퀴즈 관리자

- 새로운 퀴즈를 추가하고 등록된 퀴즈를 확인한다.

---

## 유저 플로우

### 프로그램 실행

1. 프로그램 실행
2. `StateRepository`가 `state.json`을 불러온다.
3. 파일이 없으면 기본 퀴즈 데이터를 생성한다.
4. 파일이 손상되었으면 안내 메시지를 출력하고 기본 데이터로 복구한다.
5. 메인 메뉴를 출력한다.

### 퀴즈 풀기

1. 메뉴에서 '퀴즈 풀기' 선택
2. 저장된 퀴즈를 차례대로 출력
3. 사용자가 정답 번호 입력
4. 정답 또는 오답 여부 출력
5. 모든 문제 풀이 후 총점과 정답 개수 출력
6. 기존 최고 점수보다 높으면 최고 점수 갱신
7. `StateRepository`를 통해 `state.json`에 저장

### 퀴즈 추가

1. 메뉴에서 '퀴즈 추가' 선택
2. 문제 내용 입력
3. 선택지 4개 입력
4. 정답 번호 입력
5. 입력값 검증
6. 새로운 퀴즈를 목록에 추가
7. `StateRepository`를 통해 `state.json`에 저장

### 퀴즈 목록 확인

1. 메뉴에서 '퀴즈 목록' 선택
2. 등록된 퀴즈 번호와 문제 출력
3. 퀴즈가 없으면 안내 메시지 출력

### 최고 점수 확인

1. 메뉴에서 '점수 확인' 선택
2. 저장된 최고 점수 출력
3. 플레이 기록이 없으면 안내 메시지 출력

### 프로그램 종료

1. 메뉴에서 '종료' 선택
2. 현재 퀴즈와 최고 점수를 저장
3. 종료 메시지 출력
4. 프로그램 종료

---

## 기능 요구사항

### 메인 메뉴

```text
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 최고 점수 확인
5. 종료
```

- 메뉴 번호를 입력 받는다.
- 입력 앞뒤 공백을 제거한다.
- 빈 입력을 처리한다.
- 숫자가 아닌 입력을 처리한다.
- 허용 범위를 벗어난 번호를 처리한다.
- 잘못된 입력 시 메뉴를 다시 출력한다.

---

### Quiz 클래스

퀴즈 한 문제를 표현한다.

#### 속성

- `question`: 문제 내용
- `choices`: 선택지 목록
- `answer`: 정답 번호

#### 메서드

- `display()`: 문제와 선택지를 출력한다.
- `check_answer(user_answer)`: 사용자의 답이 정답인지 확인한다.
- `to_dict()`: 객체를 JSON 저장용 딕셔너리로 변환한다.
- `from_dict()`: 딕셔너리를 Quiz 객체로 변환한다.

#### 제약사항

- 선택지는 4개
- 정답 번호는 1부터 4까지의 정수

---

### QuizGame 클래스

게임의 실행 흐름과 상태를 관리한다.

#### 속성

- `quizzes`: Quiz 객체 목록
- `best_score`: 최고 점수
- `repository`: StateRepository 객체

#### 메서드

- `run()`: 프로그램 실행
- `show_menu()`: 메인 메뉴 출력
- `play_quiz()`: 퀴즈 풀이 진행
- `add_quiz()`: 새로운 퀴즈 추가
- `list_quizzes()`: 퀴즈 목록 출력
- `show_best_score()`: 최고 점수 출력
- `get_number_input()`: 숫자 입력 및 검증
- `get_text_input()`: 문자열 입력 및 검증
- `exit_game()`: 저장 후 프로그램 종료

---

### StateRepository 클래스

`state.json`의 저장과 불러오기를 담당한다.

#### 속성

- `state_file`: 저장 파일 경로

#### 메서드

- `load()`: `state.json`에서 퀴즈와 최고 점수를 불러온다.
- `save(quizzes, best_score)`: 퀴즈와 최고 점수를 저장한다.

---

### 기본 퀴즈

프로그램에 기본 퀴즈를 5개 이상 포함한다.

```json
{
  "question": "문제 내용",
  "choices": [
    "선택지 1",
    "선택지 2",
    "선택지 3",
    "선택지 4"
  ],
  "answer": 2
}
```

기본 퀴즈는 `create_default_quizzes()` 함수에서 생성하며 다음 상황에서 사용한다.

- 프로그램을 처음 실행하는 경우
- `state.json` 파일이 없는 경우
- `state.json` 파일이 손상된 경우

---

### 파일 저장

프로젝트 루트의 `state.json` 파일에 데이터를 저장한다.

#### 저장 데이터

```json
{
  "quizzes": [
    {
      "question": "문제 내용",
      "choices": [
        "선택지 1",
        "선택지 2",
        "선택지 3",
        "선택지 4"
      ],
      "answer": 2
    }
  ],
  "best_score": 4
}
```

#### 요구사항

- UTF-8 인코딩을 사용한다.
- 한글이 이스케이프되지 않도록 저장한다.
- 퀴즈를 추가한 직후 저장한다.
- 최고 점수를 갱신한 직후 저장한다.
- 프로그램 종료 시 저장한다.

---

### 예외 처리

#### 사용자 입력

- 빈 문자열 입력
- 숫자가 아닌 값 입력
- 허용 범위를 벗어난 숫자 입력
- `Ctrl + C` 입력
- 입력 스트림 종료(`EOFError`)

#### 파일 처리

- `state.json` 파일 없음
- JSON 형식 오류
- 필수 데이터 누락
- 파일 읽기 실패
- 파일 쓰기 실패

#### 처리 기준

- 오류 원인을 안내한다.
- 가능한 경우 이전 메뉴로 돌아간다.
- 프로그램이 traceback을 출력하며 비정상적으로 종료되지 않도록 한다.
- 종료 시 가능한 범위에서 데이터를 저장한다.

---

## 완료 조건

- 메뉴가 정상적으로 반복해서 출력된다.
- 퀴즈 풀기가 동작한다.
- 퀴즈를 추가할 수 있다.
- 퀴즈 목록을 확인할 수 있다.
- 최고 점수를 확인할 수 있다.
- 기본 퀴즈가 5개 이상 존재한다.
- 프로그램 재실행 후 추가한 퀴즈가 유지된다.
- 프로그램 재실행 후 최고 점수가 유지된다.
- 파일이 없거나 손상되어도 프로그램이 실행된다.
- `Quiz`, `QuizGame`, `StateRepository` 클래스가 존재한다.
