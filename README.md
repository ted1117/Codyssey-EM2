# 나만의 퀴즈 게임

터미널에서 문제를 풀고 새로운 문제를 직접 등록할 수 있는 Python 콘솔
프로그램입니다. 퀴즈와 최고 기록을 JSON 파일에 저장하므로 프로그램을 종료한
뒤 다시 실행해도 이전 상태가 유지됩니다.

## 프로젝트 개요

이 프로젝트는 Python의 기본 문법, 클래스와 객체, 예외 처리, 파일 입출력을
활용하여 만든 콘솔 퀴즈 게임입니다. 사용자는 메뉴에서 퀴즈 풀기, 퀴즈 추가,
퀴즈 목록 확인, 최고 점수 확인 기능을 선택할 수 있습니다.

게임의 실행 흐름, 퀴즈 데이터, 점수 기록, 파일 저장 기능을 각각 별도의
클래스와 모듈로 나누어 관리합니다.

## 퀴즈 주제 및 선정 이유

주제는 **Python 기초와 입문자를 위한 기초 상식**입니다. Python을 처음 배우는
과정에서 접하는 자료형, 반복문, 함수, 예외 처리, 리스트 등의 개념을 퀴즈로
복습할 수 있도록 기본 문제를 구성했습니다. 또한 사용자가 관심 있는 상식
문제를 직접 추가할 수 있어 하나의 주제에 제한되지 않고 자신만의 퀴즈 모음으로
확장할 수 있습니다.

## 실행 환경

- Python 3.10 이상
- 운영체제: Windows, macOS, Linux
- 실행에 필요한 외부 라이브러리 없음

## 실행 방법

저장소를 내려받은 뒤 프로젝트 루트에서 다음 명령을 실행합니다.

```bash
python3 main.py
```

Windows 환경에서 `python3` 명령을 사용할 수 없다면 다음과 같이 실행합니다.

```bash
python main.py
```

프로그램이 시작되면 원하는 메뉴 번호를 입력합니다.

```text
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 종료
```

숫자가 아닌 값, 빈 값 또는 메뉴 범위를 벗어난 숫자를 입력하면 안내 메시지가
출력되고 다시 입력할 수 있습니다.

## 기능 목록

- 저장된 모든 문제를 풀고 정답 여부와 최종 점수 확인
- 문제, 선택지 4개, 정답 번호를 입력하여 새로운 퀴즈 등록
- 등록된 퀴즈의 번호와 문제 목록 확인
- 지금까지 기록한 최고 점수와 정답 개수 확인
- 퀴즈 추가 및 최고 기록 갱신 시 `state.json`에 즉시 저장
- 프로그램 종료 후 재실행해도 퀴즈와 최고 기록 유지
- 빈 입력, 잘못된 숫자, 범위를 벗어난 입력 처리
- `Ctrl+C` 또는 입력 스트림 종료 시 가능한 상태를 저장하고 안전하게 종료
- 저장 파일이 없거나 손상된 경우 기본 퀴즈 데이터로 실행

## 데이터 파일 설명

퀴즈 데이터와 최고 기록은 프로젝트 루트의 `state.json`에 UTF-8 인코딩으로
저장됩니다. 한글을 그대로 확인할 수 있도록 JSON 저장 시 유니코드 이스케이프를
사용하지 않습니다.

`state.json`은 다음 구조를 사용합니다.

```json
{
  "quizzes": [
    {
      "question": "문제 내용",
      "choices": [
        "선택지 1",
        "선택지 2",
        "선택지 3",
        "선택지 4"
      ],
      "answer": 1
    }
  ],
  "best_record": {
    "total": 5,
    "correct": 4
  }
}
```

- `quizzes`: 저장된 퀴즈 목록
- `question`: 문제 내용
- `choices`: 네 개의 선택지
- `answer`: 1부터 4까지의 정답 번호
- `best_record`: 최고 기록이며 아직 플레이하지 않았다면 `null`
- `total`: 최고 기록을 세운 게임의 전체 문제 수
- `correct`: 최고 기록을 세운 게임의 정답 수

`state.json`이 없으면 프로그램에 포함된 기본 퀴즈를 사용합니다. 파일을 읽을 수
없거나 JSON 데이터가 손상된 경우에는 오류를 안내하고 기본 데이터로 복구합니다.
